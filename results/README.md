# Per-seed raw results

These archives contain the per-seed raw results and per-run durations referenced in
the paper *A Neurosymbolic Benchmark for Temporal Knowledge-Graph Memory in Partially
Observable Environments*.

## Contents

| Archive | Tree | Runs |
|---|---|---|
| `roomkg-per-seed-results-temporal.tar.gz` | `training-results-simple-dqn-temporal/` | 200 (temporally informed neural controls) |
| `roomkg-per-seed-results-rest.tar.gz` | `training-results-simple-dqn/` | 200 (non-temporal neural baselines) |
| | `training-results-symbolic/` | symbolic agent sweep (all 27 TKG policy variants) |
| | `training-results-symbolic-simple/` | symbolic simple-agent runs |

Each run directory holds three files:

- `results.yaml` — per-seed scores and per-run duration
- `num_params.yaml` — model parameter count (neural runs only)
- `train.yaml` — the run configuration (agent, capacity, seed, policies)

The temporal archive also includes `_provenance/`, the launcher logs for the
200-run grid.

## What is not included

Two per-run artifacts are omitted because they are diagnostic dumps rather than
results, and together they account for roughly 49 GB:

- `q_values.yaml` — full Q-value tables
- `states_q_values_actions_val_episode=*.yaml` — per-episode state/Q-value/action traces

Both are regenerated by re-running the training scripts; see the repository README.

## Reproducing the aggregates

The aggregated series plotted in the paper live in `../data/`:

- `qa-accuracy-fig.json` — KG, TKG, LSTM and Transformer, train and test, all ten capacities, plus the 27-variant range
- `qa-accuracy-temporal-lstm.json`, `qa-accuracy-temporal-transformer.json` — the temporal controls

`plot-qa-accuracy.py` turns these into the QA-accuracy figure.
